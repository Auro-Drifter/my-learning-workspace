# My Learning Workspace

在 Windows 11 上运行的个人学习工作台。课程、组件和学习记录保存在本机。默认启动会创建五门演示课程，并生成一份示例笔记和一份两页的示例教材。

## 启动

需要 Node.js 24 或更新版本和 npm。使用 PowerShell 进入本目录后运行

~~~powershell
npm.cmd ci
npm.cmd start
~~~

打开 [本机工作台](http://127.0.0.1:4173/)。Ctrl+C 停止。日常开发可运行 `npm.cmd run dev`，访问 [开发服务](http://127.0.0.1:5173/)。已有构建时，可运行 `npm.cmd run serve` 直接启动。服务只监听 `127.0.0.1`，请使用这个地址访问。

默认数据位置是项目内的 `data/`。可以在启动前通过 PowerShell 为当前窗口指定一个独立的绝对路径或端口：

~~~powershell
$env:MLW_DATA_DIR = 'C:\LearningWorkspaceData'
$env:MLW_PORT = '4173'
npm.cmd start
~~~

## 使用

- 首页包含欢迎横幅、本地时钟、习惯打卡、番茄钟和学习待办。「编辑首页」可添加或移出内置卡片与已启用的插件，拖动卡片手柄调整顺序，并选择卡片宽度。手柄也支持 ↑ 和 ↓。布局保存后随工作台配置一起备份，移出卡片会保留打卡、计时和插件数据。
- 「编辑首页 → 添加组件」按学习、笔记、信息流及插件分组。新增卡片按需添加，涵盖快捷入口、倒计时、每日一言、任务看板、最近笔记、全库统计、那年今日、笔记嵌入、待办与日程、批注与复习、微信收件箱、聚合信息流及 RSS。
- 笔记类组件使用授权目录。任务看板与课程任务共用数据。待办与日程支持多维表格 `.duowei`，批注与复习支持 Mobile Ink 的批注索引和题库，微信收件箱支持 WeChat2Ob 消息日志和收件箱表格。导入的摘要保存在工作台配置和导出备份中。
- 「主流媒体与 RSS」展示《求是》最新一期与浙江宣传专栏，可按频道查看或点击刷新。RSS、Atom、OPML 文件仍可导入，在「已导入文章」和「订阅」中查看。
- 欢迎横幅与习惯打卡可在卡片上直接配置。「继续学习」回到最后选中的课程。番茄钟支持三种模式，离开首页或刷新后按原截止时间恢复。
- 左栏分组可独立展开，切课自动打开当前路径。每门课程都有可直接打开的链接，支持浏览器前进和后退。按 Ctrl+K（macOS 为 Cmd+K）搜索课程名或分组，用方向键和 Enter 跳转。窄窗口用左上角按钮展开课程抽屉。
- 新建或编辑课程时可直接选择现有分组、根目录，或在选中的目录下新建子分组。新分组随课程保存。课程可以在同组内排序、归档或恢复。
- 在「设置 → 外观」切换纸白、暖沙、雾绿、夜读，或调整背景色、强调色、字号和字体。修改即时预览，保存后会随配置恢复。
- 在「设置 → 插件」启停内置模块、安装附带插件或导入工作台插件包。已安装插件可加入首页，也可以在课程布局中添加。开发方法见 [插件 SDK](PLUGIN_SDK.md)。
- 点「编辑布局」，在组件库搜索并添加已有组件。按住标题拖动。放到空位可移动，拖到另一张卡片上且两张卡片都放得下时会换位。用右下角手柄缩放，也可聚焦标题，用方向键移动或按住 Shift 调整尺寸。移除或隐藏组件后，剩余卡片立即按当前顺序补位。可撤销配置、移动、隐藏、移除等草稿操作。换课会保留当前会话的草稿，点「保存布局」才写入配置。恢复默认布局也先进入草稿，保留组件内容及显隐状态。
- 「快捷入口」支持网页、课程、Obsidian、VS Code、Markdown 和 PDF。网页直接开新标签。图标可选预设、自定义字符或无图标。Obsidian 可浏览 Vault 或笔记，VS Code 可浏览文件或项目目录。选择后自动填入字段，保存布局后可从快捷入口打开。系统协议被拦截或应用未注册时，可用链接旁的「复制」取出地址或路径。
- 在「设置 → 资料文件夹」点击「选择文件夹…」，选中电脑上存放资料的位置，再点「添加文件夹」。默认可以查看笔记和 PDF。要在工作台里保存对原笔记的更改，请勾选对应选项。添加快捷入口时，可用「浏览文件…」选择已经添加过的文件夹中的文件。两个课程可以引用同一个文件，源文件保留在原位置。
- Markdown 使用 CodeMirror 编辑原文。可切换 GFM 和 KaTeX 预览。检测到磁盘版本更新时，会保留当前草稿并显示差异；复制或合并所需内容后，再重新加载磁盘版本。保存会备份上一版。PDF 支持分页、缩放与恢复每份文件的页码。
- 「作业与任务」可填标题、备注、截止日期、状态及当前课程的关联资源。「手动学习进度」保存当前章节、下一步和待巩固事项。

## 备份与恢复

**换电脑或恢复设置**。在「设置 → 备份与恢复」点击「下载备份」，并另外复制电脑上的笔记和 PDF。新工作台中选择这份备份，检查课程数量，再点「用这份备份恢复」。恢复后，在「资料文件夹」找到需要重新连接的资料，选中它现在所在的文件夹。备份包含课程、组件、资源入口、任务、学习进度、PDF 页码、外观、首页记录和已安装的插件。

**从磁盘恢复本机状态**。先停止使用该数据目录的服务，复制当前文件到保留位置。主配置损坏时，从保留的 `workspace.json.bak` 恢复为 `workspace.json`，再启动确认。目录授权 `roots.json` 对应的上一个副本是 `roots.json.bak`。磁盘备份包含服务用的 revision 或本机授权信息，界面的导入只接收界面导出的配置。若进程在写入中被强制结束并持续显示正在写入，确认所有实例已停止后检查残留的 `workspace.lock`、`roots.lock` 或 `note-locks/*.lock`，仅移走对应的残留锁。

**恢复单份 Markdown**。每次成功保存会在界面显示备份相对于数据目录的位置，备份每个文件保留一份上一版。先将备份打开或复制到独立位置，对照当前文件后手动恢复。`data/examples/` 是自动生成的示例资料，真实 Vault 由用户主动授权。

## GitHub Pages 在线体验

在线版从示例课程开始。课程、任务、首页布局和外观的更改只保存在当前浏览器，可以在设置里下载备份。示例笔记和 PDF 可查看。访问电脑上的资料、自定义插件和实时文章抓取请使用本机完整版。

运行 `npm.cmd run build:pages` 生成独立的 `dist-pages` 目录。GitHub Pages 从 `gh-pages` 分支根目录发布该目录的内容。更新体验版时，将新生成的站点文件提交到 `gh-pages`，源码提交到 `main`。

## 验证

~~~powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
~~~

端到端测试需要本机已安装 Microsoft Edge，通过 Playwright 启动隔离的无头浏览器和临时数据服务。它验证课程与布局隔离、重启后恢复、真实新标签、目录授权、Markdown 原文写入与冲突、PDF 渲染与页码、任务与进度，以及向全新数据目录导入配置。端到端检查会验证桌面协议链接的格式，原生应用启动由 Windows 处理。

## 工程结构与范围

- `shared/` 定义版本化配置、动作类型和验证。
- `server/` 实现回环 HTTP 接口、原子存储、目录授权和资源读写。
- `src/widgets/` 定义组件注册与编辑，`src/features/` 实现课程、文件、任务和阅读功能。
- `src/services/` 统一处理动作、API 请求和保存反馈。
- `tests/` 覆盖数据、服务和浏览器端到端行为。

Markdown 限 UTF-8 和 1 MiB，PDF 限 128 MiB；目录列表每次最多显示 500 个结果。目录授权只处理本机普通文件，符号链接、目录联接和硬链接不支持。Markdown 预览显示图片替代文字，并保留 Obsidian 专用语法的原文。原子替换前会再次校验磁盘版本，应用内的写入通过锁串行化。其他应用仍可在最后一次检查和替换之间修改该文件，遇到同时保存时可用备份核对。受密码保护的 PDF、网页嵌入预览和 P1 AI、跨设备同步留待后续。
